# Mobile app screenshots

Drop your (unedited) mobile app screenshots here for the landing page's
interactive phone showcase. Crop each one to just the phone screen area —
do not otherwise alter the image. Required filenames:

- `home.png` — the Home screen
- `tournaments.png` — the Tournaments list
- `feedback.png` — the Feedback screen
- `goals.png` — the Improvement Goals screen
- `more.png` — the More menu

Any missing file shows a labeled placeholder in the phone frame until added.
